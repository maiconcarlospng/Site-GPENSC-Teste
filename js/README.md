# JavaScript do site público

Scripts desta pasta implementam funcionalidades executadas no navegador, incluindo a Árvore do Conhecimento, galerias, notícias, acessibilidade e interações.

Referências principais:
- `arvore.js` e `arvore-interativa.js`: árvore e navegação interativa.
- `galeria-home.js` e `galeria-sobre.js`: galerias independentes.
- `paginacao-noticias.js`: navegação pelo acervo de notícias.
- `acessibilidade-gpensc.js`: controles de acessibilidade.
- `carrosseis-instagram.js` e `acervo-instagram.js`: apresentação do acervo importado.

Não renomeie arquivos sem atualizar suas referências em páginas, HTML e configuração de recursos do Quarto. Verifique a sintaxe com `node --check` e teste no desktop e no celular.
